# Data

**Everything in this folder is fictional.** Harbourline Bank does not exist. All
customer names, account numbers, sort codes, card digits, phone numbers, emails,
addresses and dates of birth are invented. Phone numbers use the Ofcom range set
aside for drama (07700 900000–900999), emails use the reserved `example.com`
domain, and every account number and sort code was randomly generated.

| File | What it is |
|---|---|
| `policies/*.md` | Seven short fictional bank policies. Each clause has an ID (e.g. `ESC-3`) so the AI must cite it. |
| `complaints.json` | 25 synthetic complaints with messy case notes. This is all the app sees. |
| `labels.json` | The answer key used only by the evaluation script: personal data actually present, product, root cause, severity, vulnerability, specialist team, applicable clauses, missing handover fields. |

`complaints.json` and `labels.json` are generated by `scripts/build_dataset.py`
from the hand-written scenarios in `scripts/scenarios.py`. Fictional personal
details are inserted with a fixed random seed, so the dataset is reproducible and
the redaction ground truth is exact.
